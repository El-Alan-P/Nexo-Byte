# CampusConecta

**Equipo:** Nexo Byte

## Descripción del proyecto

CampusConecta es una aplicación web para centralizar la consulta y gestión de eventos de una comunidad universitaria.

## Objetivo

Facilitar que los estudiantes descubran actividades universitarias, consulten los detalles de los eventos y se inscriban. Asimismo, permitirá que los organizadores autorizados creen, publiquen y administren sus eventos.

## Funcionalidades previstas

- Registro de usuarios mediante correo institucional.
- Inicio de sesión y control de acceso por roles.
- Consulta, búsqueda y filtrado de eventos.
- Creación, edición, publicación y cancelación de eventos.
- Inscripción y cancelación de inscripciones.
- Consulta de participantes y disponibilidad.
- Gestión de eventos favoritos.

## Alcance inicial

El sistema estará dirigido a una sola universidad. Los eventos serán publicados directamente por organizadores autorizados.

## Estado del proyecto

El proyecto se encuentra en la etapa de preparación y definición de requisitos.

## Tecnologías
